# Rock-Paper-Scissors
Камень, ножницы, бумага. Мини-игра против компьютера

### Что реализовано:
- Импортирована библиотека random
- Созданы переменные для вариантов: камень, ножницы и бумага
- Реализован ввод выбора пользователя через input()
- Добавлена проверка корректности ввода с помощью if и логического оператора or
- Использован print() для вывода результатов проверки

### Игровая логика:
-  Пользователь выбирает один из трёх вариантов: камень, ножницы или бумага
-  Программа проверяет корректность введённого значения
-  при правильном вводе выводится сообщение о принятии выбора
-  Компьютер с помощью библиотеки random выбирает: камень, ножницы или бумага
-  После через условные операторы if и elif идёт определение победителя
